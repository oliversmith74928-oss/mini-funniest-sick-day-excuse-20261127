# The Funniest Sick-Day Excuse

An entry for the make.fun bounty [The Funniest Sick-Day Excuse](https://make.fun/bounty/u-zeroxfive-the-funniest-sick-day-excuse-37423a36).

`main.py` (Python standard library only) writes one line to `entry.txt` — a single funny, half-believable excuse to call in sick, under 200 characters:

> My sleep tracker says I ran a marathon in my sleep, so I'm calling in sick to recover from a race I don't remember entering.

Run it with `MAKEFUN_OUTPUT_DIR` set to the output directory; it writes nothing anywhere else.
